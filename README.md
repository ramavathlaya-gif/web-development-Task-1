# 🌐 Task-1: My First Webpage

## 📌 Project Overview
This project is a simple webpage built using **HTML, CSS, and JavaScript**. It demonstrates the basic structure of a website, including headings, paragraphs, images, links, and interactive buttons.

## 🚀 Features
- Responsive webpage layout
- Heading and paragraph
- Sample image display
- External link to Google
- Interactive button using JavaScript
- Separate HTML, CSS, and JavaScript files

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
```
Task-1/
│── index.html
│── style.css
│── script.js
└── README.md
```

## ▶️ How to Run
1. Download or clone this repository.
2. Open the **Task-1** folder.
3. Double-click `index.html` or open it with **Live Server** in Visual Studio Code.
4. Click the **"Click Me"** button to see the JavaScript functionality.

## 📸 Preview
The webpage contains:
- A welcome heading
- A short paragraph
- A sample image
- A Google link
- An interactive button

## 🎯 Learning Objectives
- Understand the basic structure of an HTML document.
- Link external CSS and JavaScript files.
- Add images and hyperlinks.
- Create simple user interactions with JavaScript.
